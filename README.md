# 🌐 Personal Portfolio Website

A simple, responsive personal portfolio website built with **HTML, CSS, and JavaScript** to showcase my skills, education, projects, and experience.

## ✨ Features

- Navigation bar with quick links (Home, Projects, Skills, Education, Contact)
- Sections for technical skills, internship experience, achievements, education, and leadership roles
- Project showcase with GitHub links
- Contact section with LinkedIn, GitHub, and LeetCode profiles
- Welcome alert and click logging using JavaScript

## 📂 Project Structure

```
├── index.html    # Page structure and content
├── style.css     # Styling and layout
├── script.js     # Welcome alert and nav click logging
└── README.md
```

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/<your-repo>.git
   ```
2. Open `index.html` in any web browser.

No installation or build steps needed.
